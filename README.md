# Computer Architecture

Digital logic and processor designs from my computer engineering courses at the University of Ottawa, built in **Intel Quartus Prime** for the **Altera DE2-115 (Cyclone IV E)** FPGA board.

| Project | What it is |
|---|---|
| [8-Bit Processor](8-Bit%20Processor) | A full 8-bit accumulator CPU: 8-bit ALU, registers, program counter, 256-byte RAM and a control unit, running a Fibonacci program |
| [ALU Design](ALU%20Design) | A 4-bit ALU with arithmetic and logic circuits, an output register and carry, overflow, negative and zero flags |
| [Modulo 60 Design](Modulo%2060%20Design) | A modulo-60 counter built from flip-flops |
| [Decoder Design](Decoder%20Design) | A decoder circuit |
| [Full Adder Design](Full%20Adder%20Design) | A 1-bit full adder, the building block of the ALUs |

**Tools:** Intel Quartus Prime 13.0 SP1 · VHDL · SystemVerilog · block diagrams (BDF) · waveform simulation
